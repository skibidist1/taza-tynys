# Таза Тыныс: как сдать проект на hackathon.kz

**Главное:** на hackathon.kz **нет формы и кнопки «Сдать»**. Сдача идёт через GitHub: у команды есть свой репозиторий в организации `hackathon-kz`. Сданным решением считается **последний коммит в ветке `main` на 27.11, 23:00 (Астана)**. Залейте всё **до 20:00**, ближе к дедлайну GitHub бывает медленным.
Источник: https://hackathon.kz/github

Готовый проект лежит здесь: https://github.com/skibidist1/taza-tynys (код + `submission/`: презентация, видео, описание, шпаргалка). Его нужно скопировать в репозиторий команды.

---

## Шаг 1. Ник GitHub в профиле hackathon.kz (каждому участнику, 2 мин)
1. Зайдите на **hackathon.kz → профиль** (hackathon.kz/profile).
2. В поле **«GitHub»** впишите только ник, например `skibidist1`, без `github.com` и без `@`. Нажмите **«Сохранить»**.
3. Сделать это должен **каждый участник команды**, а не только капитан. Без ника доступа к репозиторию не будет.

## Шаг 2. Принять приглашение в репозиторий команды (2 мин)
1. Придёт письмо «hackathon-kz invited you to collaborate…» на почту GitHub (или колокольчик на github.com).
2. Нажмите **Accept invitation**.
3. Ссылка на репозиторий команды есть на странице хакатона: вкладка **«Команды»** → ваша команда → кнопка **«GitHub»**. Адрес вида `https://github.com/hackathon-kz/<название-репозитория>`.

Если приглашения нет: проверьте ник в профиле. Приглашение придёт через несколько минут, но только когда команда допущена и этап сдачи открыт. Если не пришло — пишите в @hackathon_kzbot.

## Шаг 3. Залить проект в репозиторий команды

### Вариант А: терминал (самый быстрый, 3 минуты)
Нужны Git и вход в GitHub через `gh auth login`. Пароль от GitHub в терминале не подходит.
```bash
git clone https://github.com/skibidist1/taza-tynys.git
cd taza-tynys
git remote add hk https://github.com/hackathon-kz/<НАЗВАНИЕ-РЕПОЗИТОРИЯ-КОМАНДЫ>.git
git fetch hk
git merge hk/main --allow-unrelated-histories -m "Merge team repo"   # если в репозитории команды уже был README; если он пустой — пропустить
git push hk HEAD:main
```
Если при `merge` будет конфликт в `README.md`, оставьте наш вариант: `git checkout --ours README.md && git add README.md && git commit -m "Keep project README"`, потом снова `git push hk HEAD:main`.

### Вариант Б: GitHub Desktop (без терминала)
1. Скачайте **GitHub Desktop**, войдите своим аккаунтом.
2. **File → Clone repository** → выберите репозиторий команды `hackathon-kz/...` → **Clone**.
3. Скачайте наш проект: https://github.com/skibidist1/taza-tynys → зелёная кнопка **Code → Download ZIP**, распакуйте.
4. Скопируйте **всё содержимое** распакованной папки в папку склонированного репозитория команды. Если спросит про README — заменить.
5. В GitHub Desktop внизу слева напишите «Проект Таза Тыныс» → **Commit to main** → **Push origin**.

Вариант В (через браузер, **Add file → Upload files**) тоже работает, но для проекта на сотню файлов это неудобно, так что лучше А или Б.

## Шаг 4. Проверить, что сдано (1 мин)
Откройте репозиторий команды на github.com и проверьте, что видны:
- `README.md` — главная страница проекта, в начале ссылка на сайт https://taza-tynys.vercel.app;
- папка `submission/` с файлами `slides.pdf` (презентация, 10 слайдов), `pitch.mp4` (видео, 2:16), `DESCRIPTION.md` (описание), `DEFENSE.md` (шпаргалка);
- последний коммит в ветке **main** сделан **до 27.11, 23:00**.

После 23:00 писать в репозиторий нельзя: сайт запомнит последний коммит `main`.

## Шаг 5. Если успеете — поднимет баллы
- **2–3 разговора с завучами или учителями физкультуры** (10–15 минут). Покажите вкладку «Школа» на сайте и спросите:
  - кто решает «улица или зал»;
  - бывало ли, что отменяли улицу из-за смога;
  - как предупреждают родителей;
  - пользовались бы этим экраном.

  Одна цитата и должность.
- **Переозвучить видео своими голосами** по тексту из `submission/pitch_script.md`.
- **Название команды и участники** на слайдах.

Пришлите это передавшему проект человеку: он пересоберёт слайды и видео, и вы зальёте их тем же шагом 3. Только настоящие ответы: выдуманное интервью — это дисквалификация (п. 6.5).
